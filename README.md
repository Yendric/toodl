# Toodl

Monorepo for Toodl, a todo PWA.

- [`apps/web`](apps/web)
- [`apps/api`](apps/api)

## Development

```sh
pnpm install
pnpm dev          # runs web + api in parallel
```

The web app's API client is generated by Orval from the tsoa OpenAPI spec. After changing API routes:

```sh
pnpm gen
```
